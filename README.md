# Disciplinary Management System

A comprehensive web-based disciplinary management system designed for educational institutions and organizations to track and manage disciplinary incidents, actions, and user records.

## Features

### 📊 Dashboard
- Real-time statistics overview
- Recent activity feed
- Quick access to key metrics
- Visual indicators for system status

### 👥 User Management
- Add, edit, and delete users (students, faculty, staff, administrators)
- Role-based user categorization
- Department organization
- Complete user profiles

### 📝 Incident Management
- Record detailed disciplinary incidents
- Multiple incident types (Academic Misconduct, Behavioral Issues, Violence, etc.)
- Severity levels (Low, Medium, High, Critical)
- Status tracking (Open, Resolved)
- Location and date tracking

### ⚖️ Disciplinary Actions
- Link actions to specific incidents
- Various action types (Warning, Suspension, Probation, etc.)
- Start and end date management
- Status tracking (Pending, Active, Completed)
- Detailed action descriptions

### 📈 Reports & Analytics
- Incidents by type visualization
- Monthly trend analysis
- Statistical breakdowns
- Visual charts and graphs

## Technology Stack

- **Frontend**: HTML5, CSS3, JavaScript (ES6+)
- **Storage**: Browser localStorage (client-side persistence)
- **Hosting**: GitHub Pages compatible
- **Design**: Responsive, mobile-friendly interface

## Getting Started

1. **Access the System**: Open `index.html` in a web browser or visit the GitHub Pages URL
2. **Sample Data**: The system includes sample users to get started
3. **Navigation**: Use the top navigation bar to switch between sections
4. **Add Data**: Use the "Add New" buttons to create users, incidents, and actions

## Usage Guide

### Adding Users
1. Navigate to the "Users" section
2. Click "Add New User"
3. Fill in the required information (name, email, role, department)
4. Save the user

### Recording Incidents
1. Go to the "Incidents" section
2. Click "Record New Incident"
3. Select the user involved
4. Choose incident type and severity
5. Provide detailed description and location
6. Save the incident

### Creating Disciplinary Actions
1. Access the "Actions" section
2. Click "Add New Action"
3. Link to an existing incident
4. Select the user and action type
5. Set start/end dates if applicable
6. Add description and save

### Viewing Reports
1. Visit the "Reports" section
2. Review incident statistics by type
3. Analyze monthly trends
4. Use data for institutional planning

## Data Management

- **Persistence**: All data is stored in browser localStorage
- **Export**: Data persists across browser sessions
- **Reset**: Clear browser data to reset the system
- **Backup**: Consider exporting data regularly for backup

## Browser Compatibility

- Chrome 60+
- Firefox 55+
- Safari 11+
- Edge 16+

## Security Considerations

- Client-side storage only (no server-side data)
- Suitable for single-user or trusted environment use
- Consider server-side implementation for multi-user production environments
- Regular data backups recommended
